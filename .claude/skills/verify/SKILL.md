# التحقق من موقع كوانيني بالتشغيل الفعلي

**القاعدة:** الكود اللي "شكله صح" مش متحقّق منه. الموقع ده اتكسر أكتر من مرة بطرق **مبتبانش غير في متصفح**: الصفحة بتنطّ 123 بكسل، زرار أساسي بيطلع أصغر من رقم تليفون، الفوتر بيتغطي على الآيفون. كلها عدّت مراجعة كود.

اقرا [`quaniny-website`](../quaniny-website/SKILL.md) الأول لو التعديل معماري — ده بيقولك **إزاي تتأكد**، وده بيقولك **إيه الصح**.

## ابدأ من هنا

```bash
# 1) شغّل السيرفر المحلي (بيحاكي cleanUrls — لازم)
node .claude/skills/verify/scripts/serve.cjs &

# 2) قيس CLS و LCP
node .claude/skills/verify/scripts/measure.cjs
```

`measure.cjs` بيرجع **exit code 1** لو أي صفحة فوق 0.1، فينفع في أي فحص أوتوماتيك.

**المرجع المسجّل: `CLS = 0.000` على كل الصفحات.** أي رقم أعلى معناه إن حاجة اتكسرت دلوقتي.

> **أول مرة في الجلسة:**
> ```bash
> mkdir -p /tmp/pw && cd /tmp/pw && npm i playwright-core
> ```
> والكروم متنصّب أصلًا على `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`. **متشغّلش `playwright install`.**
>
> السكربت بيدوّر على `playwright-core` جنبه، وفي **مكان التشغيل**، وفي `PW_PATH` — فتشغيله من `/tmp/pw` كفاية.

> **ليه `.cjs` مش `.js`؟** `package.json` بتاع الريبو فيه `"type": "module"` (لازم لدوال `/api/*.mjs`)، وده بيخلي **أي** ملف `.js` في الريبو ES module فـ`require()` بيقع. **متغيّرش الامتداد.**

## ثلاث مصايد بتضيّع وقت — اعرفها قبل ما تقع فيها

### 1. `scroll-behavior: smooth` بيفسد كل قياس بعد تمرير

`style.css` فيه `scroll-behavior:smooth`. أي `window.scrollTo` بيتحرك **بالتدريج**، فلو قِست أو صوّرت بعده على طول، بتقيس نص الحركة.

ده ضلّل التحقق **مرتين** في يوم واحد: مرة قال إن الشريط بيغطي الفوتر وهو مش بيغطيه، ومرة طلعت صورة لجزء غلط من الصفحة.

```js
// قبل أي تمرير برمجي
await pg.evaluate(() => { document.documentElement.style.scrollBehavior = 'auto'; });
// أو للصور: استخدم element.screenshot() — بيمرر لوحده صح
await (await pg.$('.cta-row')).screenshot({ path: 'out.png' });
```

### 2. رسايل الكونسول بتوصل بعد ما تقرا

`pg.on('console', ...)` غير متزامن. لو ضغطت زرار وقرأت الأحداث في نفس اللحظة، هتلاقيها فاضية وتفتكر إن الحدث مش شغال.

```js
await pg.click('.add-btn');
await pg.waitForTimeout(400);   // بعدها اقرا
```

### 3. `pkill -f serve` بيقتل الشل بتاعه

لو سطر الأمر اللي بتشغّله فيه كلمة `serve` (حتى في مسار السكربت)، `pkill -f` بيطابق **الأمر نفسه** ويقتله — exit code **144** وكأن حاجة غريبة حصلت. حصل مرتين.

**الأسهل: شغّل على بورت تاني** بدل ما تقتل. `serve.cjs 8123`.

### 4. فشل التحقق مش دايمًا عطل في الكود

مرة فشل إرسال الروشتة في الاختبار، والسبب إني كتبت عنوان من 5 حروف والتحقق بيطلب 6. **الكود كان سليم.** قبل ما تقول "فيه باج"، اقرا رسالة الخطأ اللي ظهرت للمستخدم.

## إيه اللي تفحصه حسب اللي اتغيّر

| اتغيّر إيه | افحص إيه |
|---|---|
| `app.js` / `chrome()` / الهيدر | الهيدر والناف والفوتر موجودين **وبالترتيب** (الهيدر أول ابن في الـ body، الفوتر آخر واحد) · الناف النشط · بادچ السلة في المكانين · **CLS** |
| `style.css` | **CLS** + صور على `390px` و`1100px`. الجريد والفليكس بيتصرفوا مختلف عند الالتفاف |
| `.qbar` | الشريط ظاهر تحت 640px ومخفي فوقها · **الفوتر مش متغطي** لما تنزل لآخر الصفحة · `padding-bottom` الـ body |
| السلة / `/products` | إضافة منتج → البادچ 0→1 → صفحة السلة بتعرض → عدّاد التوصيل المجاني بيحسب صح |
| `/delivery` | `mode=rx` و`mode=contract` الاتنين · رفع صورة · التحقق بيرفض المدخلات الناقصة |
| أي `track()` جديد | `window.__trackDebug = true` والأحداث بتتطبع · **واختبار تسريب**: املا الفورم ببيانات مميزة واتأكد إنها مش في أي حدث |
| schema / نص FAQ | الـ JSON-LD بيتفكّ بـ `json.loads` · **نص السؤال والجواب الظاهر مطابق حرف بحرف للـ schema** |

## فحص الـ Schema والـ FAQ

النص الظاهر لازم يطابق الـ `FAQPage` schema بالظبط — لو اختلفوا، جوجل بيتجاهل الـ rich result. ده حصل فعلًا لما اتحط لينك جوه إجابة.

```bash
python3 - <<'PY'
import re, io, json, glob
for f in glob.glob('*.html') + glob.glob('*/*.html'):
    s = io.open(f, encoding='utf-8').read()
    for m in re.finditer(r'<script type="application/ld\+json">(.*?)</script>', s, re.S):
        try: json.loads(m.group(1))
        except Exception as e: print('❌', f, e)
print('✅ كل الـ JSON-LD سليم')
PY
```
