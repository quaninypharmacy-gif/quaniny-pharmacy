# Impeccable — معيار الشكل في كوانيني

الشكل هنا مش ذوق. ده **موقع صيدلية حقيقية** بتتعامل مع ناس بتشوفها في الشارع، وكل تغيير بصري بيتحاسب بتلات أرقام: **التباين**، **السرعة**، و**ثبات التخطيط**.

اقرا الأول: [`BRAND.md`](../../../BRAND.md) (التوكنز والمكوّنات) · [`AGENTS.md`](../../../AGENTS.md) (قواعد التعاون) · [`quaniny-website`](../quaniny-website/SKILL.md) (المعمار).

## 🔴 خمس قواعد متتكسرش

### 1. الإثبات مقارنة بالبكسل، مش «شكله زي ما هو»

أي تعديل بتقول عنه «بصري بس» أو «مش هيغيّر الشكل» **لازم يتثبت**:

```bash
node .claude/skills/verify/scripts/serve.cjs 8123 &
# صوّر قبل · نفّذ · صوّر بعد · قارن
```

المقارنة بتمسك حاجات العين بتفوّتها. **حصل فعلًا:** `sizes="60vw"` على صورة الهيرو خلّى الديسكتوب ياخد صورة 800px لمكان 1280px — الفرق قفز من 4% لـ15%، وده كان تشويش حقيقي. الأرقام قالت «أسرع»، والمقارنة قالت «أوحش».

**القراءة:** فرق أقل من ~6% داخل صورة فوتوغرافية = ضوضاء ترميز، مقبول. فرق في نص أو حدود أو مسافات = **تراجع**.

### 2. التباين بيتحسب مش بيتشاف

```python
def lum(h):
    h=h.lstrip('#'); r,g,b=(int(h[i:i+2],16) for i in (0,2,4))
    f=lambda c:(c/255)/12.92 if c/255<=.03928 else (((c/255)+.055)/1.055)**2.4
    return .2126*f(r)+.7152*f(g)+.0722*f(b)
def ratio(a,b):
    l1,l2=sorted([lum(a),lum(b)],reverse=True); return (l1+.05)/(l2+.05)
# نص عادي ≥ 4.5:1 · نص كبير أو عنصر واجهة ≥ 3:1
```

> **الدرس المسجّل:** تدقيق خارجي قال «الرمادي تباينه ضعيف». **القياس قال 7.2:1 و7.6:1 — سليم.** اللي كان ساقط فعلًا: **سعر المنتج 2.56:1** (أهم رقم في صفحة تجارة، وأقل حاجة مقروءة فيها)، ووصف الكروت 2.24:1 و2.60:1. **خمّن غلط في المكان، وقيس صح في مكان تاني.**

**والبرتقالي لونين مش لون** — `--orange` للأسطح الداكنة بس، و`--orange-ink` للنص على فاتح. لون واحد ميقدرش يعمل الدورين.

### 3. الترتيب: `style.css` بعدين `design.css`

`design.css` بيدوس على 109 محدد من `style.css`. **متقلبش الترتيب ومتدمجهمش** — الدمج بيكسر شغل كودكس على `design.css` مقابل ~150ms مش محسوسة. (اتناقش واتقفل، سبتمبر 2026.)

لو بتضيف قاعدة جديدة، **حطها في `design.css`** واستخدم محدد بنفس القوة أو أعلى — **متستخدمش `!important`** إلا في `prefers-reduced-motion`.

### 4. اللي ممنوع تلمسه — اتكسر قبل كده

| العنصر | القاعدة | ليه |
|---|---|---|
| `.cta-row` | **Grid، مش Flex** | بـFlex طلع الرقم 346px والزرار الأساسي 165px |
| `chrome()` | **أول سطر في الـ body**، والفوتر مؤجّل | نقلها لآخر الصفحة رفع الـ CLS لـ 0.146 |
| `body{padding-bottom}` | **في CSS مش JS** · `calc(74px + env(safe-area-inset-bottom))` | من غير `env()` الشريط بيغطي الفوتر على آيفون |
| الصور | `width`+`height` أو `aspect-ratio` **دايمًا** | من غيرها الصفحة بتنطّ |
| لوجوهات التأمين | بألوانها ونِسبها — **تصغير أيوه، قص/تلوين/رسم لأ** | علامات تجارية بإذن محدد |

### 5. الصور: الموبايل مياخدش مقاس الديسكتوب

`srcset` بمقاسين + `sizes` **مضبوط على المقاس الفعلي**. ولو فيه `preload` للصورة، لازم يشيل `imagesrcset` و`imagesizes` **مطابقين** — وإلا المتصفح بيحمّل النسختين.

اللوجو اللي بيتعرض 140px **متخزّنوش 1200px**. (كان فيه لوجو بـ124 كيلو — أتقل من كل الـ CSS بعد الضغط.)

## الترتيب اللي بيمشي

```
1. اقرا  → BRAND.md + الصفحة الحالية. متبدأش من فراغ
2. قِس   → CLS/LCP + تباين + صور «قبل»
3. شخّص  → أكبر 10 مشاكل بالقياس، مرتبة بالأثر
4. نفّذ  → توكنز الأول، بعدين المكوّنات، بعدين الصفحات
5. أثبت  → صور «بعد» + مقارنة بالبكسل + إعادة قياس
6. وثّق  → أي قاعدة اتعلمتها بالغلط تتكتب هنا أو في BRAND.md
```

## علامات إن الشغل مش تمام

- **`!important` جديدة** → المحدد ضعيف، صلّح المحدد
- **قيمة مش من السلّم** (خط أو نصف قطر أو مسافة) → استخدم التوكن
- **لون جديد** مش في `BRAND.md` → إما يتضاف للهوية رسميًا أو ميتحطش
- **إيموجي في واجهة جديدة** → `BRAND.md` بيمنعها، استخدم `assets/icons.svg`
- **«حسّنت الشكل» من غير صور قبل/بعد** → مش متحقّق منه

## اللي التدقيق مبيمسكهوش — وانت لازم تمسكه

- **أداة الاختبار نفسها بتكذب.** سيرفر التطوير مفهوش `.svg` في جدول الـ MIME، فاللوجوهات طلعت «مكسورة» وهي سليمة على Vercel. **قبل ما تبلّغ عن عطل، اتأكد إنه مش في أداة القياس.**
- **`line-height` مبيكبّرش صندوق العنصر السطري.** `display:inline-block` + `padding` هو اللي بيكبّر هدف اللمس.
- **قياس واحد مش دليل.** فيه إزاحة بتظهر في 2 من 8 تحميلات. لو شفت رقم غريب، **كرّر 6 مرات** قبل ما تحكم.
