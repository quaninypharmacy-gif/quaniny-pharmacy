# صيدلية كوانيني — موقع الصيدلية

موقع ثابت (HTML/CSS/JS) + دوال Serverless على Vercel.

## الصفحات

| الملف | الغرض |
|---|---|
| `index.html` | الرئيسية — الهيرو، كروت الإجراءات، شركات التأمين، التواصل |
| `delivery.html` | صرف الروشتة والتعاقدات (يومي/شهري + رفع صور + إرسال فوري أو واتساب) |
| `products.html` | عرض المنتجات |
| `product.html` | صفحة المنتج (بتقرأ `?id=` من الرابط) |
| `cart.html` | السلة وإتمام الطلب |
| `branches.html` | الفروع بخرايط جوجل |
| `ask.html` | اسأل الصيدلي (واتساب) |
| `app.js` | بيانات المنتجات + منطق السلة + الهيدر والفوتر المشتركين |
| `style.css` | كل التنسيقات |

## الدوال (`/api`)

| الملف | الغرض |
|---|---|
| `order.mjs` | استقبال طلبات المتجر → تليجرام + Supabase |
| `prescription.mjs` | استقبال طلبات الروشتة والتعاقدات + صور → تليجرام + Supabase |
| `refills.mjs` | Cron يومي 9 صباحًا: تنبيهات إعادة الصرف للعلاج الشهري |
| `health.mjs` | تشخيص: بيقول المتغيرات موجودة ولا لأ، والاتصال بتليجرام وقاعدة البيانات |

> الامتداد `.mjs` مقصود، ومعاه `"type": "module"` في `package.json` — من غيرهم الدوال مش هتشتغل.

## Environment Variables (من Vercel، مش من الكود)

```
TG_BOT_TOKEN
TG_CHAT_ID
SUPABASE_URL
SUPABASE_SERVICE_KEY
CRON_SECRET
```

كلهم لازم يكونوا على **Production**، وبعد أي تعديل فيهم لازم **Redeploy**.

للتأكد: افتح `/api/health` — المفروض كل القيم `true` و`telegram: "ok:@..."` و`db: "ok"`.

## قاعدة البيانات

شغّل `schema.sql` مرة واحدة في Supabase → SQL Editor.

## إضافة منتج جديد

في `app.js` جوه مصفوفة `PRODUCTS`، انسخ الكارت الموجود وغيّر:
`id`, `name`, `brand`, `price`, `img`, `video`, `short`, `uses`

وارفع صورة المنتج في جذر المشروع بنفس الاسم المكتوب في `img`.

## ملاحظات

- الأسعار بتتحسب في السيرفر (`api/order.mjs`) مش في المتصفح.
- صور الروشتة بتتصغّر في متصفح العميل قبل الإرسال.
- مفيش أي أسرار في الكود — كله من Environment Variables.
